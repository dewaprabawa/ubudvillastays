# Ubud Villa Stays

Marketing site for **The Hideaway** — a single 2-bedroom private pool villa in Tirta Tawar, Ubud, Bali.

## Stack

- Next.js 15 (App Router) + TypeScript
- CSS Modules + design tokens
- `next/image`, Metadata API, JSON-LD, sitemap, robots

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
